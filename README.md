
# Finite Automatа & Regular Expressions


Конзолно приложение за работа с **Крайни Автомати** (Детерминирани и Недетерминирани с $\epsilon$-преходи) и **Регулярни Изрази (RegEx)**. Приложението дава възможност за създаване на автомат от регулярен израз, основни операции върху автомати, разпознаване на думи, както и визуализация в graphviz.

---

##  команди в CLI


| Команда | Описание |
| :--- | :--- |
| `open <file>` | Зарежда автомати от посочения текстов файл. |
| `save <id> <file>` | Записва конкретен автомат с даденото ID във файл. |
| `saveall <file>` | Записва цялата база от заредени автомати в един файл. |
| `list` | Списък на всички автомати в паметта |
| `print <id>` | Отпечатва текст със състоянията и преходите. |
| `deterministic <id>`| Проверява дали автоматът е ДКА. |
| `determinise <id>` | Детерминира автомата. |
| `minimise <id>` | Минимизира автомата. |
| `reverse <id>` | Обръща автомата. |
| `recognise <id> <word>` | Проверява дали думата се разпознава от автомата (ползва `@` за $\epsilon$). |
| `union <id1> <id2>` | Създава нов автомат като обединение на два съществуващи. |
| `concat <id1> <id2>`| Създава нов автомат като конкатенация на два съществуващи. |
| `star <id>` | Създава нов автомат който е звездата на Клини върху избрания автомат. |
| `reg <regex>` | Парсва регулярен израз и генерира автомат по него. |
| `draw <id> <file>` | Генерира `.dot`файл за графична визуализация. |
| `exit` | Затваря приложението безопасно. |
